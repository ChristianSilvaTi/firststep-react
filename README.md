# Library React

> 🇧🇷 [Português](#português) | 🇺🇸 [English](#english)

---

## Português

Aplicação web front-end de uma biblioteca, desenvolvida utilizando **React** e **Vite**.

### Funcionalidades

- Interface web para uma biblioteca.
- Exibição e organização de livros.
- Componentes React reutilizáveis.
- Interface moderna e responsiva.

### Tecnologias utilizadas

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- JavaScript (ES6+)
- HTML5
- CSS3

### Como executar o projeto localmente

**Pré-requisito:** ter o [Node.js](https://nodejs.org/) instalado na máquina.

1. Clone este repositório:

   ```bash
   git clone https://github.com/ChristianSilvaTi/firststep-react.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd firststep-react
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse o endereço exibido no terminal, geralmente `http://localhost:5173`.

### Build de produção

Para gerar os arquivos otimizados para produção:

```bash
npm run build
```

Para visualizar a versão de produção localmente:

```bash
npm run preview
```

## English

A front-end library web application developed using **React** and **Vite**.

### Features

- Web interface for a library.
- Book display and organization.
- Reusable React components.
- Modern and responsive interface.

### Technologies

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- JavaScript (ES6+)
- HTML5
- CSS3

### Getting Started

**Prerequisite:** [Node.js](https://nodejs.org/) must be installed on your machine.

1. Clone this repository:

   ```bash
   git clone https://github.com/ChristianSilvaTi/firststep-react.git
   ```

2. Navigate to the project folder:

   ```bash
   cd firststep-react
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the URL displayed in the terminal, usually `http://localhost:5173`.

### Production Build

To generate the optimized production files:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
